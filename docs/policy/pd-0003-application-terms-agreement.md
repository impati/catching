# PD-0003: 신청 약관 동의

- **날짜:** 2026-08-17
- **대체:** 해당 없음
- **대체됨:** 해당 없음

## 배경과 문제

이벤트 신청에는 개인정보 제공 등 신청 목적의 약관이 포함될 수 있다. 필수 약관과 선택 약관을 구분하지 않거나 동의하지 않은 회원의 신청을 그대로 진행하면 신청에 필요한 동의 요건을 보장할 수 없다.

## 목표

회원이 신청 약관을 확인하고 필수 약관에 동의한 뒤 신청하도록 하되, 선택 약관 거부는 신청을 막지 않게 한다.

## 정책

- **PD-0003-R1:** 신청에 사용하는 약관은 `APPLY_FOR` 목적의 그룹으로 관리하며, 각 약관은 필수 또는 선택으로 구분한다.
- **PD-0003-R2:** 회원의 동의 이력이 없는 약관은 미동의 상태로 취급한다.
- **PD-0003-R3:** 신청 약관 그룹의 모든 필수 약관은 동의 상태여야 한다. 필수 약관이 누락됐거나 거부 상태면 동의 저장을 성공시키지 않는다.
- **PD-0003-R4:** 선택 약관은 동의하지 않아도 필수 약관 검증과 신청 진행을 막지 않는다.
- **PD-0003-R5:** 같은 회원이 같은 약관의 동의 상태를 다시 제출하면 기존 상태를 최신 제출 값으로 바꾼다. 약관별 현재 상태는 하나만 유지한다.
- **PD-0003-R6:** 신청 화면의 정상 흐름은 약관 동의 상태를 저장하고 필수 약관 검증에 성공한 뒤 실제 신청을 요청한다.
- **PD-0003-R7:** 신청 약관 그룹에 약관이 하나도 없으면 별도의 동의 없이 신청을 진행할 수 있다.

## 거절하는 시나리오

- 필수 약관을 제출하지 않거나 거부한 상태로 약관 동의를 완료한다.
- 필수 약관 검증이 실패했는데 실패한 제출 값을 현재 동의 상태로 저장한다.

## 허용하는 시나리오

- 모든 필수 약관에는 동의하고 선택 약관에는 동의하지 않은 채 신청한다.
- 이전에 동의한 약관을 나중에 철회해 현재 상태를 미동의로 바꾼다.
- 신청 약관이 없는 이벤트의 신청을 바로 진행한다.

## 정책이 정하지 않는 것

- 약관과 동의 상태의 저장 형식
- 약관 화면의 배치와 표현 방식

## 미결

- 실제 신청 요청이 저장된 필수 약관 동의를 서버에서 다시 검증해야 하는지에 대한 목표와 현재 적용 범위가 일치하지 않는다.
- 제출한 약관 ID가 신청 약관 그룹에 속하는지 검증하는 범위가 확정되어 있지 않다.
