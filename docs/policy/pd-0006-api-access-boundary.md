# PD-0006: 외부·관리자 API 접근 경계

- **날짜:** 2026-08-17
- **대체:** 해당 없음
- **대체됨:** 해당 없음

## 배경과 문제

시스템은 외부 사용자가 접근하는 기능과 운영자가 관리하는 기능을 별도 애플리케이션으로 나눈다. 어떤 기능이 공개되고 어떤 기능이 운영자 전용인지 경계가 없으면 배포 구성 변경이나 프록시 설정 실수로 관리 기능이 외부에 노출될 수 있다.

## 목표

외부 사용자가 필요한 공개·회원 기능과 운영자 전용 관리 기능의 접근 주체를 분명히 한다.

## 정책

- **PD-0006-R1:** 활성 이벤트 목록·상세와 신청 약관 내용은 로그인하지 않은 외부 사용자도 조회할 수 있다.
- **PD-0006-R2:** 개인 신청 결과, 약관 동의 상태, 추가 정보와 회원 정보는 인증된 해당 회원만 접근할 수 있다.
- **PD-0006-R3:** 이벤트 생성·승인, 입력 필드와 약관 관리는 외부 사용자에게 공개하지 않는 운영자 전용 기능이다.
- **PD-0006-R4:** 현재 운영자 전용 기능은 내부망 배포 경계를 신뢰한다. 이 경계를 보장할 수 없는 환경에서는 외부 노출 전에 별도의 관리자 인증·인가 정책을 결정해야 한다.

## 거절하는 시나리오

- 외부 사용자가 이벤트 생성·승인이나 필드·약관 관리 기능에 접근한다.
- 한 회원이 다른 회원의 신청 결과, 약관 동의 또는 추가 정보를 조회한다.

## 허용하는 시나리오

- 비로그인 사용자가 현재 공개 중인 이벤트와 신청 약관을 미리 확인한다.
- 인증된 회원이 자신의 신청 상태와 추가 정보를 확인한다.

## 정책이 정하지 않는 것

- 내부망을 구성하는 네트워크·프록시 방식
- 향후 관리자 인증 수단과 역할 모델

## 재검토 조건

- 관리자 애플리케이션이 내부망 밖에 배포되거나 내부망 접근 주체가 운영자로 한정된다는 보장을 유지할 수 없을 때 재검토한다.
