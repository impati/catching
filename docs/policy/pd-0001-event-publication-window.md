# PD-0001: 선착순 이벤트 공개 범위

- **날짜:** 2026-08-17
- **대체:** 해당 없음
- **대체됨:** 해당 없음

## 배경과 문제

등록된 이벤트가 곧바로 외부 사용자에게 노출되거나, 예정된 공개 기간 밖에서도 조회되면 운영자가 검토하지 않은 이벤트나 종료된 이벤트가 신청 대상으로 오인될 수 있다.

## 목표

운영 승인을 받고 공개 기간에 들어온 이벤트만 외부 사용자가 발견하고 상세 내용을 조회할 수 있게 한다.

## 정책

- **PD-0001-R1:** 새로 만든 이벤트는 승인되기 전까지 외부 사용자에게 공개하지 않는다. 운영 준비가 끝나지 않은 이벤트가 신청 대상으로 노출되는 것을 막기 위함이다.
- **PD-0001-R2:** 승인된 이벤트는 현재 시각이 노출 시각 이상이고 종료 시각 이하일 때 외부 목록과 상세 조회에 공개한다. 노출 시각과 종료 시각은 모두 공개 범위에 포함한다.
- **PD-0001-R3:** 종료 시각이 지난 이벤트는 외부의 활성 이벤트 조회에서 제외한다.
- **PD-0001-R4:** 이벤트 시작 시각과 노출 시각은 각각 종료 시각보다 앞서야 한다. 종료 이전에 시작하거나 공개할 수 없는 일정은 유효하지 않다.

## 거절하는 시나리오

- 승인되지 않은 이벤트를 외부 목록이나 상세에서 조회한다.
- 노출 시각 전에 이벤트를 외부에서 조회한다.
- 종료 시각이 지난 이벤트를 활성 이벤트로 조회한다.
- 시작 시각 또는 노출 시각이 종료 시각과 같거나 그보다 늦은 일정으로 이벤트를 만든다.

## 허용하는 시나리오

- 현재 시각이 노출 시각과 정확히 같은 승인 이벤트를 조회한다.
- 현재 시각이 종료 시각과 정확히 같은 승인 이벤트를 조회한다.

## 정책이 정하지 않는 것

- 생성·승인·활성 상태를 코드에서 표현하는 방식
- 공개 대상 조회를 저장소에서 구현하는 방식

## 미결

- 실제 신청 가능 시작을 `startAt`으로 볼지, 외부 공개가 시작되는 `displayAt`으로 볼지는 현재 자료가 일치하지 않아 별도 결정이 필요하다.
