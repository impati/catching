# refresh token 저장 방식 점검

- **ID:** BL-0004
- **기록일:** 2026-08-16

## 배경

외부 프론트엔드는 access token 만료 시 refresh token으로 토큰을 갱신하는 흐름을 가진다. 보안 점검 과정에서 refresh token이 브라우저 저장소에 보관될 경우 XSS 발생 시 장기 세션 탈취로 이어질 수 있다는 위험이 확인되었다.

refresh token은 access token보다 수명이 길고 재발급 권한을 가지므로, 저장 위치와 전송 방식이 외부망 서비스의 인증 안전성에 직접적인 영향을 준다.

## 목표

refresh token 저장 방식과 갱신 흐름을 점검한다. 브라우저 저장소 사용의 위험, HttpOnly 쿠키 전환 가능성, 로그아웃과 갱신 실패 처리, refresh token 재사용과 만료 처리 관점에서 현재 흐름을 검토하고 필요한 보완 방향을 도출한다.
