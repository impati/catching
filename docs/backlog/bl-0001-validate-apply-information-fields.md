# 신청 정보 필드 검증 강화

- **ID:** BL-0001
- **기록일:** 2026-08-16

## 배경

외부 사용자 신청 플로우에서 `/v1/comes/{comeId}/information` 요청 body의 `informations`는 사용자가 직접 조작할 수 있는 입력이다. 보안 점검 과정에서 신청 정보 저장 시 해당 필드가 실제로 그 선착순 이벤트에 속한 필드인지, 필수 필드가 누락되지 않았는지, 선택형 필드 값이 허용된 값인지 등을 확인해야 한다는 필요가 발견되었다.

이 검증이 약하면 사용자가 API body를 조작해 이벤트에 정의되지 않은 정보를 저장하거나, 필수 정보를 누락한 채 신청 완료 상태로 넘어갈 수 있다. 이는 외부망에서 직접 시도 가능한 데이터 무결성 문제로 이어질 수 있다.

## 목표

신청 정보 입력 단계에서 사용자가 제출한 필드와 값이 해당 선착순 이벤트의 필드 정의와 일치하는지 확인한다. 필수 필드 누락, 이벤트에 속하지 않은 필드 제출, 선택형 필드의 허용되지 않은 값, 길이와 형식 제한 누락 같은 위험을 점검하고 필요한 보완 작업을 도출한다.
