# 신청 약관 동의 검증 점검

- **ID:** BL-0002
- **기록일:** 2026-08-16

## 배경

신청 플로우에서는 실제 신청 전에 `APPLY_FOR` 약관을 노출하고 사용자의 동의 상태를 저장한다. 프론트 화면에서는 필수 약관 동의 여부를 확인하지만, 외부 사용자는 클라이언트를 우회해 API를 직접 호출할 수 있다.

보안 점검 과정에서 필수 약관 미동의 상태에서도 신청이 가능한지, 요청에 포함된 약관 ID를 조작했을 때 서버가 올바르게 막는지, 약관 그룹과 약관 ID의 관계가 정확히 검증되는지 확인할 필요가 발견되었다.

## 목표

신청 약관 동의가 서버 측에서 충분히 검증되는지 점검한다. 필수 약관 미동의, 다른 그룹의 약관 ID 제출, 존재하지 않거나 조작된 약관 ID 제출, 약관 동의 저장과 실제 신청 사이의 흐름을 확인해 신청 전 동의 요건이 우회되지 않도록 한다.
