# 관리자 API 내부망 경계 점검

- **ID:** BL-0005
- **기록일:** 2026-08-16

## 배경

시스템은 `external`만 외부망이고 `admin` 등 나머지 모듈은 내부망이라는 가정을 두고 있다. 이 가정이 지켜지면 관리자 API는 외부 사용자가 직접 호출할 수 없지만, 네트워크 경계가 유일한 방어선이면 프록시 설정 실수나 배포 환경 변경 시 관리자 기능이 무인증으로 노출될 수 있다.

보안 점검 과정에서 관리자 API가 내부망 전제에만 의존해도 되는지, 최소한의 인증과 인가가 필요한지 검토할 필요가 발견되었다.

## 목표

관리자 API의 네트워크 경계와 인증 요구 수준을 점검한다. 내부망 전제가 깨졌을 때 노출될 수 있는 생성, 승인, 필드, 약관 관리 API를 확인하고, 운영 환경에서 관리자 기능이 의도한 접근 주체에게만 허용되도록 필요한 보완 방향을 도출한다.
